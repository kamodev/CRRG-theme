A configurable theme for the Castle Rock Repeater Group amateur radio club.

== Description ==

CRRG is a classic (PHP) WordPress theme with options for every part of the
layout, all managed in Appearance > Customize:

* Front page sections: hero banner, info bar, feature cards, page content,
  latest posts, call to action and two widget areas, each with its own
  on/off switch and a drag-and-drop order.
* Three header layouts, an optional top bar, sticky and transparent headers,
  a header button, search and social icons, and a slide-in or drop-down
  mobile menu with a configurable breakpoint.
* Five content layouts (right sidebar, left sidebar, both sidebars, no
  sidebar, full width) chosen per content type, per post or page, or with a
  page template.
* Fourteen widget areas and five menu locations.
* Colour presets plus 18 individual colours, Google or system fonts, and
  container, sidebar, corner and logo sizes.
* Club widgets (repeaters, net schedule, contact, call to action, social
  icons, recent posts) and block patterns (repeater table, nets,
  membership, FAQ and more).

See README.md in the theme repository for the full option reference.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click Add New Theme.
2. Click Upload Theme and choose the theme's ZIP file, then click Install Now.
3. Click Activate.
4. Go to Appearance > Customize to configure the theme.

== Frequently Asked Questions ==

= Where do I change the layout of a single page? =

Use the "CRRG Layout" box in the editor sidebar, or choose one of the
layout templates under Page Attributes / Template.

= How do I stop loading Google Fonts? =

Customize > CRRG Theme Options > Typography > Font source > System fonts only.
